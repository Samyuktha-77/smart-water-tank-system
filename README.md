# 💧 Smart Water Tank Management System

A web-based Smart Water Tank Management System designed to monitor water levels, display motor status, and support remote motor-control commands using Firebase.

## 🚀 Project Overview

This project aims to make water tank management easier by providing a dashboard that displays tank-level information and motor status in real time.

The current version is a software prototype. Physical hardware integration is planned for a future stage.

## ✨ Features

- 📊 Water-level dashboard
- 💧 Animated water tank visualization
- ⚙️ Motor ON/OFF controls through the website
- 🔥 Firebase Realtime Database integration
- 🚨 Water-level and motor-status display
- 📱 Foundation for future hardware integration

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Realtime Database
- Git and GitHub

## 🏗️ System Architecture

Website Dashboard ↔ Firebase Realtime Database

Future planned integration:

Water-Level Sensor → ESP32 → Firebase → Website Dashboard

Physical motor control and sensor integration are not yet implemented.
